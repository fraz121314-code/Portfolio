# Portfolio

An interactive portfolio and CV. The page responds to how visitors move:

- **Mood field:** the cursor grows moss-like strands, and movement speed sets a mood (calm, curious, playful, restless) that tints the whole page.
- **Gathering name:** the name is made of particles that scatter from the cursor and gather back.
- **Liquid glass cards:** frosted panels that tilt and catch light under the pointer.
- **Leave a line:** visitors draw, and the drawing is redrawn as one continuous plotter-style line.

## Make it yours

Edit `src/content/site.ts` (name, intro, projects, experience, skills, links) and put your CV at `public/cv.pdf`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
